# Valhalla Combat — native menu build

Install the archive as a complete replacement of Valhalla Combat in your mod manager. Its root corresponds to Skyrim's `Data` directory. Enable `ValhallaCombat.esp` and install the matching SKSE and Address Library for your game. Install SKSE Menu Framework 3.8 / API 1 to use the native menu. TrueHUD and Precision remain optional integrations. This build targets SE and AE with one DLL; VR is excluded.

Open SKSE Menu Framework and select **Valhalla Combat → Settings 设置**. The default page displays all 66 gameplay settings, starting with the execution hotkey, stun meter and automatic execution. Buttons filter stamina, blocking/tackle, stun/execution and effects/compatibility. Numeric labels appear above full-width controls. Both execution and alternate-block hotkeys support keyboard, mouse and gamepad capture, readable key names and unbinding. Chinese/English is saved with the other preferences. Use Apply to save, Undo to discard the draft, Defaults to prepare default values, or Reload to discard the draft and read the INI again. Diagnostics contains integration status, saved/effective revisions and execution status.

Configuration is created at `Data/SKSE/Plugins/ValhallaCombat/Settings.ini`. First launch merges built-in defaults, any legacy MCM defaults, the historical SKSE INI, then MCM user overrides. A legacy same-path file is backed up to `.legacy.bak`; `[Meta] Schema=1` prevents repeated migration. Leave old configuration files available for this first launch. Do not install a default INI over your existing settings. Missing Menu Framework leaves gameplay and file configuration available.

Settings apply globally to every save and persist after restarting the game. Successful save loads and new games reapply the saved configuration, including regeneration and TrueHUD meter state. Changes apply through the game task queue, including while paused. The archive contains no default Settings.ini, so installing this update preserves existing preferences.

Disable the old Valhalla mod files before installing this replacement, then keep its legacy configuration files for migration. The new archive includes no MCM JSON, MCM PEX or Scaleform menu assets. Its ESP removes the menu-only quest and unused MCMHelper/SkyUI masters; the other 249 records and their FormKeys are verified unchanged. Other mods may still require MCMHelper/SkyUI; retain those dependencies when needed. Previously saved Papyrus script instances are part of the save and are not edited by this package.

Gameplay keeps the established light-stun default of zero, 3-second recovery delay plus 7-second regeneration, subsequent-hit automatic execution and key-down execution input. The perfect-block setting uses accumulation count. Unsupported level-limit/player-execution settings are not exposed as working controls.

Heavy attacks use the engine's stamina cost, matching current upstream. Custom heavy-hit/heavy-miss ratios and their menu controls have been removed; old ratio keys are ignored when loading configuration. Light-hit rewards, light-miss costs and the actor-specific noncombat waiver remain available. The blocked-hit reward setting applies to light attacks.

This revision passed a Release compilation and 17 host regression suites. The menu suite exercises the registered settings callback, all controls, execution binding, INI round trips, category navigation and language persistence. Lifecycle tests cover configuration reapplication after loading saves and starting new games. Stun and exhaustion calculations use the runtime-aware ActorValueOwner accessor for SE and AE; regression actors require that accessor. These tests do not render the actual Menu Framework or run combat physics. In-game checks remain for menu layout/fonts, controller navigation, paused input, TrueHUD display and the reported sinking/shaking. See the [2026-11-06 source audit](audits/2026-11-06-source-audit.md) for earlier ABI and trace verification.
